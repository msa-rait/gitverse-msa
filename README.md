# GITVERSE - MSA Workshop: Git & GitHub

Welcome to the MSA Workshop Repository!

This repository is a space for students to learn how developers collaborate on projects using Git and GitHub.

## What Can You Do Here?

- Add your name to the contributors list.
- Practise Git commands.
- Create your own branch.
- Make changes to files.
- Commit and push your changes.
- Open a Pull Request.
- Learn how collaborative development works.

## Contribution Challenge

Try completing these tasks:

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch.
4. Add your name and a short introduction to `contributors.md`.
5. Commit your changes.
6. Push your branch to GitHub.
7. Open a Pull Request.

## Contributors

Contributors are students who participate in this workshop and practise collaborative development.

Add your name to `contributors.md` to get started!

## Why Git and GitHub?

Git helps developers track changes in their code, while GitHub makes it easier to share projects, review contributions, and collaborate with others.

## Remember

- Write meaningful commit messages.
- Keep your changes focused.
- Use descriptive branch names.
- Review your changes before opening a Pull Request.
- Learn from mistakes and keep experimenting.

**Learn by doing. Build together. Contribute to open source.**
